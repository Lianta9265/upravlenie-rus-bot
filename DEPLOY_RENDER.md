# Развёртывание на Render — короткий маршрут

Эта инструкция нужна только когда вы решите сделать бота доступным без включённого компьютера.

1. Создать новый GitHub-репозиторий и загрузить содержимое этой папки.
   `.env` НЕ загружать.
2. На render.com выбрать New → Blueprint.
3. Подключить GitHub-репозиторий. Render увидит `render.yaml`.
4. Когда Render попросит переменные окружения, вставить:
   - BOT_TOKEN — актуальный токен от BotFather;
   - GEMINI_API_KEY — ключ Google AI Studio.
5. Запустить deploy.
6. В логах должно появиться `Telegram webhook установлен.`
7. Открыть Telegram и написать боту любое тестовое слово.

На бесплатном Web Service возможен «сон» при отсутствии трафика, поэтому первый ответ
после долгого простоя может прийти не мгновенно. Для гарантированной постоянной готовности
нужен платный экземпляр Render без автоматического засыпания.

После успешного деплоя не запускайте локальный `bot.py`: режим polling отключает webhook.
