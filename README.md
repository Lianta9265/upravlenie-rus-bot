# «Управление и сочетаемость»

Telegram-бот-справочник по нормам управления и лексической сочетаемости русского языка.

[Открыть бота](https://t.me/upravlenie_rus_bot) · `Python` · `Flask` · `Telegram Bot API` · `Gemini API`

> Словарные ответы имеют приоритет. ИИ используется только как явно помеченная
> черновая подсказка, если статьи ещё нет в локальной базе.

## Возможности

1. Принимает слово, словоформу или целую фразу.
2. Находит опорное слово в локальной базе из **42 статей и 208 алиасов**.
3. Для найденной статьи показывает:
   - значения;
   - падежные вопросы;
   - модели управления;
   - короткие примеры и сочетания;
   - типичные ошибки, если они зафиксированы;
   - название источника.
4. Если проверенной статьи пока нет, обращается к Gemini API.
   Ответ ИИ обязательно помечается как черновой и не выдаётся за словарную норму.
5. Поддерживает команды:
   - `/start`
   - `/help`
   - `/sources`

## Почему две части

Норму задаёт словарная база. ИИ — вспомогательный слой для неизвестных запросов.
Это защищает от ситуации, когда языковая модель уверенно придумывает неверное управление.

## Как выглядит ответ

```text
СЛОВО: оплатить

УПРАВЛЕНИЕ:
• что? — оплатить проезд, счёт, покупку

ПРИМЕРЫ:
• Оплатить проезд банковской картой.

ИСТОЧНИК:
• справочный словарь управления
✓ Проверено по локальной словарной базе.
```

## Локальный запуск

Требуется Python 3.10+.

1. Скопируйте `.env.example` в `.env`.
2. Заполните в нём `BOT_TOKEN` и `GEMINI_API_KEY`.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python bot.py`.

При локальном запуске программа сама отключает Telegram webhook и начинает polling.

## Постоянная работа в интернете (Render)

Проект уже подготовлен для Web Service через `render.yaml`.
Секреты **не находятся в репозитории**: `BOT_TOKEN` и `GEMINI_API_KEY` задаются в панели Render.
`webhook.py` автоматически использует `RENDER_EXTERNAL_URL` и устанавливает Telegram webhook.

Важно: если после облачного развёртывания запустить локально `python bot.py`,
локальная версия отключит webhook. Для постоянной облачной работы локальный bot.py
после развёртывания лучше не запускать.

## Файлы

- `bot.py` — локальный Telegram polling.
- `webhook.py` — облачная webhook-версия.
- `src/core.py` — поиск и оформление словарной статьи.
- `src/gemini_client.py` — безопасный ИИ-фолбэк.
- `src/telegram_common.py` — общая Telegram-логика.
- `data/entries.json` — проверенная стартовая база.
- `data/sources.json` — реестр источников.
- `render.yaml` — развёртывание на Render.

## Безопасность

- `.env` включён в `.gitignore`.
- Токены не печатаются в логах.
- Технические ошибки Telegram не выводятся вместе с URL, где мог бы оказаться токен.
